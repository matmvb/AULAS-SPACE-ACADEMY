# Desafio – Sistema de Inventário

## Objetivo
Criar um sistema de inventário para um jogo usando Listas, Dicionários e LINQ.

## Instruções

1. Complete a classe `Item` com:
   - Propriedades: `Nome`, `Tipo`, `Valor`
   - Construtor que recebe nome, tipo e valor
   - Método `ToString()` formatado

2. No `Program.cs`, complete os trechos marcados com `// TODO`:

   a) Criar uma lista de itens (pelo menos 5 itens diferentes)
   b) Criar um dicionário para controlar quantidades
   c) Preencher o dicionário com as quantidades
   d) Exibir todos os itens
   e) Filtrar apenas as armas usando LINQ
   f) Ordenar os itens por valor (maior para menor)
   g) Encontrar os 3 itens mais valiosos

3. DESAFIO EXTRA (para quem terminar):
   - Agrupar os itens por tipo e mostrar a quantidade de cada tipo
